## 🇮🇹 Descrizione (Italiano)
Configurazione ottimizzata dei file `Skyrim.ini` e `SkyrimPrefs.ini` per Skyrim Special/Anniversary Edition, 
pensata per GPU come **GTX 660 (2GB VRAM)** e risoluzione **1080p**.
Obiettivo: massima qualità visiva e stabilità senza ENB o mod grafiche aggiuntive.

### Caratteristiche principali
- FXAA attivo, TAA disattivato → testi nitidi e UI pulita  
- Ombre 2048px, distanza 3500 → stabilità e realismo  
- Luce volumetrica attiva, gamma 1.27 → contrasto naturale  
- Prestazioni: ~60 FPS medi su GTX660, 1080p fullscreen

### Installazione
1. Backup dei file originali in `Documenti/My Games/Skyrim Special Edition/`
2. Copiare `Skyrim_VEV-P.ini` e `SkyrimPrefs_VEV-P.ini` nelle stesse posizioni, rinominandoli in `Skyrim.ini` e `SkyrimPrefs.ini`
3. Impostare i file in **Sola Lettura**
4. Avviare il gioco tramite `skse64_loader.exe`

## 🇬🇧 Description (English)
Optimized configuration for `Skyrim.ini` and `SkyrimPrefs.ini` (Special/Anniversary Edition).  
Target hardware: **GTX 660 2GB VRAM**, **1080p resolution**.

### Main Features
- FXAA enabled / TAA disabled → sharp text and UI
- 2048px shadows, 3500 distance → stable performance
- Volumetric lighting ON, gamma 1.27 → realistic light
- Performance: ~60 FPS avg on GTX660 @1080p fullscreen

### Installation
1. Backup your original files in `Documents/My Games/Skyrim Special Edition/`
2. Copy `Skyrim_VEV-P.ini` and `SkyrimPrefs_VEV-P.ini` into the same folder (rename as `Skyrim.ini` and `SkyrimPrefs.ini`)
3. Set both files to **Read-only**
4. Launch Skyrim via `skse64_loader.exe`
